# mdview kata

- user friendly md viewer (editor)
- deno + aio framework app (dep/aio)
- app uses aio framework correctly using latest api and recommendations 


## Meta
- mdview current version is v0.3.2
- app window (electron) is showing title mdview [version]
- version is also stated on main page like mdivew [version]

## General
- app never freezes
- app is always responsive
- app is bug free 
- every app state is maintained 
- there are no unpredictable scenarios


## Features
- dark/white theme (persisted setting, switchable using button on panel)

## Files
- mdview can open local md files
- mdview can open remote md files that are linked
